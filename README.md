# 🏡 Wyszukiwarka Mieszkań Multi-Portal + Lokalne Biura Nieruchomości

Inteligentna wyszukiwarka ofert mieszkań, która łączy w jednym miejscu ogłoszenia z:
- **Otodom**
- **OLX**
- **Lokalnych Biur Nieruchomości** (z bazą dla Jeleniej Góry i okolic oraz możliwością dodawania dowolnych nowych biur i miast).

## 🚀 Jak uruchomić?
Wystarczy dwukrotnie kliknąć plik:
👉 **`uruchom.bat`**

Aplikacja uruchomi się automatycznie w Twojej przeglądarce internetowej pod adresem `http://localhost:8501`.

## ✨ Funkcje:
1. **Kalkulator całkowitych kosztów („Ze wszystkim”):**
   - W przypadku Otodom program pobiera zarówno odstępne, jak i czynsz administracyjny do spółdzielni i sumuje je, by pokazać realny koszt miesięczny.
2. **Katalog i wyszukiwanie lokalnych biur nieruchomości:**
   - Dedykowana zakładka z bezpośrednimi linkami do baz wynajmu lokalnych biur (np. *Team4Home*, *Nieruchomości Dudek*, *Gold House*, *Aplauz*, *Stępień*, *Perfect* itp.).
   - Przycisk wyszukiwania dodatkowych biur w internecie oraz formularz dodawania własnych agencji.
3. **Filtry i preferencje:**
   - Wybór miasta (domyślnie: Jelenia Góra, ale można wpisać dowolne inne).
   - Budżet maksymalny.
   - Opcja „Tylko bezpośrednio od właściciela (bez prowizji biura)”.
   - Wybór źródeł (możesz odznaczyć lub zaznaczyć wybrane portale).
4. **Wykrywanie duplikatów:**
   - Jeśli to samo mieszkanie jest wystawione na Otodom i OLX, program wyświetli żółte ostrzeżenie.
5. **Ulubione:**
   - Możliwość zapisywania interesujących ogłoszeń na liście porównawczej.
